## ⚡ Highlights

- **Featured Architecture:** Interactive showcases of production platforms including **LoanIQ** (AI underwriting), **Mukti Portal** (VYOMA 2026 1st runner-up), **VisionKirana** (CV retail lending), **SkyBanking** (Enterprise Java 21), and **ANTARIKSH-OS** (satellite edge radar).
- **Visual Milestone Showcase:** 3D auto-advancing circular carousel highlighting academic topper awards, cash prizes, and hackathon presentations with full-screen blurry backdrop modals.
- **Verified Certifications Grid:** Category-filtered credential vault (TCS CodeVita Rank 2143, Google Cloud, IBM, Adobe Hackathon, Hero Campus Challenge, LeetCode 100-Day Badge).
- **Performance & Core Web Vitals:** Hardware-composited smooth scrolling, demand-driven RAF loops, and 0ms main-thread INP latency.
- **Developer Dashboards:** Real-time GitHub contribution metrics and LeetCode algorithmic problem-solving activity calendar.

## 🛠️ Tech Stack

- **Framework:** Next.js 15 (App Router, Turbopack, RSC)
- **Frontend:** React 19, TypeScript, Tailwind CSS
- **Animations:** Framer Motion
- **Icons & UI:** Lucide React, React Icons, Sonner
- **Markdown & Blog:** Next-MDX-Remote, Rehype Pretty Code

## 🚀 Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/shiv123-coder/Shivshankar_Mali_Portfolio.git
cd Shivshankar_Mali_Portfolio

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
